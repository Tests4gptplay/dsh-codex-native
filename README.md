# DSH Codex Native 0.2.1-alpha.5

Install: github:Tests4gptplay/dsh-codex-native#v0.2.1-alpha.5

Official Codex app-server main-model adapter. Settings now offers manual account usage queries using account/usage/read, with native DSH Button/DisclosureRow and skin-owned theme tokens.
